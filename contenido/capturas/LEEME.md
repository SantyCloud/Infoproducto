# Capturas para la landing

Sube aquí las capturas que se mostrarán en la página de venta.

**Antes de subirlas, difumina los nombres, números de teléfono y fotos de tus clientes.**
Este repositorio es público y, además, las capturas se verán en la web.

Nombres sugeridos (así sé en qué sección va cada una):

- `mensajes-1.jpg`, `mensajes-2.jpg`… → chats llenos de mensajes de clientes
- `ingresos-1.jpg`, `ingresos-2.jpg`… → ingresos o ventas
- `testimonio-1.jpg`… → mensajes de clientes o alumnos contentos

JPG o PNG, del tamaño que sea: se optimizan para que la web cargue rápido.

**Cómo subirlas desde GitHub:** entra en esta carpeta → **Add file** → **Upload files** →
arrastra las imágenes → **Commit changes**.
